# Project Docs

This directory is for human-facing project documentation that should be shared with teammates or adapted into the final report.

Use this directory for stable project documentation that is useful to the team.

## Current Documents

- `project_structure.md`: repository layout and ownership boundaries.
- `experiments.md`: experiment naming, outputs, and reproducibility notes.
- `round06_plan.md`: Round 06 retrieval and reranking experiment plan.
- `experiment_report_current.md`: current summary of completed retrieval experiments.
- `retrieval_error_examples.md`: examples showing why current retrievers miss gold evidence.
- `figures/round06_confusion_matrix_figures/`: confusion matrix figures for the current retrieval and reranking methods.
